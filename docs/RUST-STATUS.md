# Rust + Lua: промежуточная версия 17.11.2026

Это промежуточная сборка. Наличие реализации и локального теста не означает,
что все облачные сервисы уже проверены на колонке с реальными аккаунтами.
Go-ядро не менялось. Старые native-плагины поддерживаются на время переноса.

## Последующие исправления

- `0.9.82-rs` переносит сбор и разметку коротких записей, архив и длительный
  фон в Rust-модуль «Обучение слова». Старые локальные записи доступны в том же
  разделе и сохраняются отдельно от лимита новых записей (1–5 МБ).
  В длительном режиме колонка сжимает примерно минуту фона в памяти и сама
  отправляет архив в Nextcloud File Drop или Koofr. Ссылка «Только загрузка»
  или пароль приложения нужны один раз. При ошибке выгрузки запись останавливается.
  Архив на колонке собирается из локальных записей. Старые облачные файлы
  остаются в прежнем хранилище.
- Плеер показывает состояние музыки Алисы, позицию и метаданные и направляет
  паузу, перемотку и смену трека активному источнику. YouTube предлагает
  продолжение персонально выбранного видео после окончания воспроизведения.
  Включение следующего видео требует согласия.

  подключения микрофона при загрузке. Проверена сборка ядра без default features.

## Реализовано, но перенос ещё не закончен

- VPN на Rust: VLESS TCP/WebSocket, TLS, REALITY, Vision и SOCKS5.
  Есть тесты с независимым Xray-сервером. REALITY поддерживает Chrome 133
  (`fp=chrome`/`chrome133`) с X25519+ML-KEM, GREASE, перестановкой расширений и Brotli,
  а также Firefox 120 (`fp=firefox`/`firefox120`) с ключами X25519 и P-256.
  SOCKS5 UDP ASSOCIATE передаёт пакеты через VLESS UDP; UDP с Vision пока требует XUDP.
  Браузерные профили доступны для REALITY. Пока нет остальных fingerprints,
  ML-DSA, gRPC/XHTTP и остальных неподдерживаемых режимов из README модуля.
  Профили закреплены на версиях 133 и 120. Параметры ссылки не удаляются молча.
- ChatGPT по подписке: вход устройства, обновление токена, Codex SSE,
  WebRTC, кодек Opus, запросы к бэкенду и постоянный ID чата.
  Локальный тест проверяет SDP, данные, звук и запрос к бэкенду.
  Проверен реальный облачный звонок через Rust VPN с REALITY/Chrome: входящая речь,
  распознавание, ответ модели и Opus. WebRTC использует SOCKS UDP, если модуль VPN
  явно поддерживает его; со старым провайдером остаётся только TCP ICE без прямого обхода.
- OpenAI, Gemini, Grok: текст с инструментами и потоковые голосовые сессии.
  ElevenLabs: STT, TTS и каталог голосов. Обычный голосовой режим
  STT → LLM → TTS реализован. Проверка всех реальных облачных протоколов ещё нужна.
## Осталось

- Проверка ElevenLabs Realtime на реальном аккаунте, быстрый STT и полное резервирование моделей/ключей.
- Автоматический подбор и замена Rust-сборки при выборе модулей в панели.
  Сейчас код выбирается Cargo features при сборке на компьютере.
- Оставшиеся API обновлений, статистики, предпросмотра,
  управления пользовательскими голосами и части подключений.
- Проверить новые подключения, прерывание речи, длительную работу и нагрузку
  на реальной колонке. Старые замеры памяти нельзя считать замерами этой сборки.

Lua и Opus используют встроенные C-библиотеки; захват и проигрывание звука
также опираются на штатные компоненты колонки. Перенос на Rust относится к
ядру и логике подключений, а не к переписыванию ОС и всех сторонних библиотек.
